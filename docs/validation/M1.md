## 2. 关键行为

- 饥饿按 `hunger_decay_seconds` 下降；低于 18 时从背包或双手取食物进食，并少量回血；
  归零后每 5 秒受到 1 点饥饿伤害。
- 生命低于 `low_health_percent` 时停止寻路、清除目标，MCP 移动与交互返回
  `unsafe_area`；恢复后重新接受动作。
- `follow` 只在 `follow` 行为下运行；`stay` 坐下；`guard` 只把 `Monster` 作为候选
  目标，且不会追击到 home 半径之外。
- `canAttack` 明确排除：主人、任何玩家、村民、任何有主人的宠物。
- 管理界面包含 9 格背包、6 格装备、玩家背包与快捷栏；提供行为切换、设置/清除 home、
  删除二次确认和改名输入。删除时背包或装备非空会被拒绝。
- MCP 开发端点启动/停止会同步到客户端的 `MCP on/off` 指示。

```powershell
$env:JAVA_HOME="$env:USERPROFILE\.jdks\jdk-25.0.5.1+2"
$env:PATH="$env:JAVA_HOME\bin;$env:PATH"

.\gradlew.bat :core:test :mcp:test

.\gradlew.bat :fabric:runGameTestServer
# All 26 required tests passed

.\gradlew.bat :fabric:runClientGametest -Ptlmm.graphicsBackend=vulkan
# BUILD SUCCESSFUL；截图：
# run/clientGametest/screenshots/0000_m1-companion-render.png
# run/clientGametest/screenshots/0001_m1-companion-screen.png

.\gradlew.bat build
# BUILD SUCCESSFUL
```

`runClientGametest` 的流程：

1. 新建单人世界，执行 `execute as @a at @s run tlmm summon`。
2. 客户端右键同伴，打开 `CompanionScreen`。
3. 截图管理界面。
4. 点击界面上的行为按钮，服务端行为从 `follow` 切到 `guard`。

截图确认：实体渲染正常；界面显示 `Companion`、生命、饥饿、半径、背包/装备占用和
`MCP off`；按钮与改名输入框在面板内，无文字溢出。
