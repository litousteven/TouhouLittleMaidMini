# M6.2 模块库验收

日期：`2026-11-21`

范围：区域农作、按标签采集、砍树、箱子整理；`craft_item` / `smelt_items` /
`deposit_items` / `withdraw_items` 已在 M6.1 交付。

## 1. 实现

| 模块 | 风险 | 要点 |
|---|---|---|
| `harvest_area` | `MODIFY` | 半径内按距家排序，每 tick 一块；成熟才收；`replant` 从背包取任意 `CropBlock` 种子补种 |
| `plant_area` | `MODIFY` | 只在已有耕地上补种，不需要锄 |
| `till_area` | `MODIFY` | 必须有锄（`#minecraft:hoes`），否则 `tool_not_in_inventory`；翻地后扣耐久，可选补种 |
| `mine_material` | `DESTROY` | 由 tags/ids 选点，不出现具体矿物 id；家半径 16 格内跳过；工具检查复用 `Tools` |
| `chop_tree` | `DESTROY` | 固定只认 `#minecraft:logs`，不动树叶与树苗 |
| `tidy_chests` | `MODIFY` | 索引 → 规划 → 逐槽执行 → 校验；同类归并、保留至少 1 个空箱、跳过 `#tlmm:keep` 与 `keep:` 命名箱、跳过熔炉 |

`tidy_chests` 的数量守恒按 `ItemStack.hashItemAndComponents` 统计，整理前后不一致立即
返回 `count_mismatch` 并停止；预算默认 200 次槽位移动，超出返回 `budget_exceeded`。

## 2. 验证

```powershell
.\gradlew.bat :fabric:runGameTestServer
```

结果：`77 GAME TESTS COMPLETE` / `All 77 required tests passed`。新增 9 条：

- `harvestAreaHarvestsAndReplantsEverything`：3 株成熟小麦全部收割并补种，消耗 3 颗种子。
- `plantAreaFillsEmptyFarmland`：两块空耕地补种成功。
- `tillingWithoutHoeIsRefused`：`tool_not_in_inventory`，泥土未变。
- `tillingWithHoeMakesFarmland`：木锄翻出耕地。
- `miningWithoutPickaxeIsRefused`：`tool_not_in_inventory`，石头未变。
- `miningProtectsTheHomeRadius`：石头在家半径内 → `not_harvestable`，方块未变。
- `chopTreeOnlyBreaksLogs`：原木被砍，旁边泥土未动。
- `tidyChestsMergesAndConservesCounts`：48 圆石 + 10 木板数量守恒，至少空出 1 个箱子。
- `tidyNeverTouchesKeepChests`：`keep:` 命名箱保持 32 个不变，其余两箱合并为 32。

## 3. 已知边界

- 家保护半径对 `mine_material` / `chop_tree` 恒定生效；玩家显式命令也不会在家附近开采，
  这是安全优先的选择，如需要可在后续加显式覆盖参数。
- `tidy_chests` 暂不识别「玩家正打开的箱子」与「他人容器」，因为这两项需要玩家会话与
  领地数据；当前已跳过保留箱、熔炉与空箱缓冲，其余规则随 M6.5 的机会层补齐。
- 区域模块接受 `tags` / `ids`，尚未接入 `SemanticTags` 的六档优先级（M6.3）。

## 4. 结论

**Go**：区域与整理模块全部由 GameTest 覆盖，整理满足数量守恒与「不搬出仓库」的边界。
