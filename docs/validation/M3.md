## 4. 明确的交互边界

- **空气交互与钓鱼**：原版 `FishingHook` 的 owner 必须是 `Player`
  （`getPlayerOwner()` 返回 `Player`，`retrieve()` 强转 `ServerPlayer`），因此没有
  非玩家路径。TouhouLittleMaid 的 `TaskFishing` 并不调用原版钩子，而是自带
  `MaidFishingHook extends Projectile`。按 `AGENTS.md` 不引入假玩家，本版本让
  `target_kind=air` 返回 `unsupported_interaction`；非玩家钓鱼属于后续 L2 provider。
- **非物品实体交互**：`Entity.interact(player, hand, location)` 同样要求 `Player`。
  只有 `ItemEntity` 通过拾取路径支持；村民、动物等返回 `unsupported_interaction`。
- **容器内容**：按本轮决定直接暴露槽位内容，作为明确的读取能力。上锁容器按锁码只报
  `locked=true`，不返回内容；仍不返回完整 NBT。
