| 工具 | 类别 | 状态 |
|---|---|---|
| `companion_list` | observe | 可用 |
| `companion_state` | observe | 可用 |
| `companion_context` | observe | 半径内方块统计；尚无标签/实体过滤 |

## 2. 已验证行为

- `initialize` 返回 `2025-11-25` 与 `serverInfo`。
- `tools/list` 返回 10 个工具、JSON Schema 与 annotations。
- 参数校验：缺失、类型错误、未知参数、数值下限均返回 `invalid_params`。
- 未知工具 → `unknown_tool`；未知方法 → `-32601`。
- 未知同伴 → `unknown_companion`（不再落到 `internal_error`）。
- 无 Token / 错误 Token → HTTP 401。
- Token 作用域：`TLMM_MCP_READ_ONLY=1` 时写工具返回 `scope_denied`。
- 审计：每请求一行，仅含 request id、token 摘要、工具名、companion、状态、
  code、耗时；不含 Token 本体、背包或聊天正文。
- 幂等：相同 `request_id` 重放返回缓存结果，不二次执行。
- 事件：`behavior_changed`、`operation_stopped` 单调递增；游标越界报
  `event_cursor_expired`。
- 服务器线程：所有世界操作经 `runOnServer` 提交主线程并等待，HTTP 线程不直接改世界。
- 停服：一次运行内 `[mcp] listening` → `[mcp] stopped`，端口释放。

## 4. 阻塞项：`companion_interact`

现象：无法让同伴实体右键方块。

根因：Minecraft `26.3` 的方块交互入口只接受玩家：

```java
InteractionResult useItemOn(ItemStack, Level, Player, InteractionHand, BlockHitResult)
InteractionResult useWithoutItem(Level, Player, BlockHitResult)
```

`CompanionEntity` 不是 `Player`，因此没有可直接调用的交互路径。

已做的处理：`companion_interact` 明确返回 `unsupported_interaction` 并附带方块 ID，
而不是伪造成功、模拟 Player 或改写 owner 的状态。GameTest
`interactionReportsThePlatformLimitInsteadOfPretending` 固定了该行为。

M3 可选的解决方向，需要先决定再实现：

1. 使用 Mojang 在 `26.3` 提供的非玩家交互入口（需进一步核查映射）。
2. 在受限条件下构造一个服务端 Bot 视图完成交互。
3. 重新界定 `interact` 的语义为"观察 + 请求 owner 交互"。

按项目宪章，这属于会改变产品边界的选择，必须先更新设计文档再实现。
